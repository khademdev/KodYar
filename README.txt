ساختار پروژه MyAI
------------------
- بک‌اند: Go (package main) — همه‌ی فایل‌های *.go در ریشه
- فرانت‌اند: frontend/ (RTL فارسی) + frontend/dist (بیلد آماده) + frontend/wailsjs (بایندینگ‌های دست‌ساز — پروتکل در ARCHITECTURE.md)
- پیش‌نیاز: Go 1.26+ (از go.dev نصب کنید)
- مستندات: README.md و ARCHITECTURE.md داخل خود پروژه

نحوه‌ی بیلد
-----------
ساده‌ترین راه: اسکریپت خود پروژه (Wails CLI را هم خودش نصب می‌کند):

    cd MyAI
    ./build.sh            # فقط ویندوز (کامپایل متقاطع، بدون پیش‌نیاز)
    ./build.sh linux      # لینوکس (نیاز به libwebkit2gtk-4.0-dev)
    ./build.sh all        # هر دو

بیلد مستقیم ویندوز بدون اسکریپت:

    cd MyAI
    GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -tags production -o MyAI.exe .

تست‌ها (۱۴۰ تابع، همه سبز):

    cd MyAI && go test -race -count=1 ./...

چیزهایی که عمداً داخل zip نیست
-------------------------------
- تاریخچه‌ی git (111MB — به‌خاطر tarball ابزار Go در تاریخچه)؛ نتیجه‌ی
  آن به‌صورت متنی در HARDENING-COMMITS.txt آمده است.
- tarball ابزار Go (67MB) — Go را از go.dev نصب کنید.
- باینری توسعه‌ی «myai» (7.7MB) — با «go build .» دوباره ساخته می‌شود.
  (نسخه‌ی production ویندوز داخل همین zip موجود است.)
